# Utah

## Horse riding

- [Paria River Ranch atlas](paria-river-ranch/README.md): four print sheets for ranch-based planning, Mount Carmel/Bay Bill and the Red Canyon riding areas. Source-linked water, trailer-access and terrain evidence; editable QGIS project and a native one-meter terrain sample. Planning draft, not field-verified or Avenza-validated.

The Paria River Ranch atlas now includes a [13-page expanded edition](paria-river-ranch/output/pdf/expanded/paria-river-ranch-expanded-atlas.pdf) with terrain exposure, seasonal snow context and camping ownership sheets.
