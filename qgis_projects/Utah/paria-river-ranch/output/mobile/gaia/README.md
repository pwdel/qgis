# Gaia GPS custom maps

Download/import the GPX for trails and planning points. Import a TileJSON definition for a custom map view, or copy its `tiles` URL into Gaia's Add Custom Map Source screen. Set zoom 8-13, preview, save and sync your iPhone. Gaia Premium is required to download maps for offline use. These are fixed styled views; use the companion PDF for legends and caveats.
